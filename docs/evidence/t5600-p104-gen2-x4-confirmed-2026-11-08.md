# T5600 P104-100: physical PCIe Gen2 x4 confirmed (2026-11-08)

## Hardware / scope

- Host: Dell Precision T5600, Intel Xeon E5-2670
- GPU0: NVIDIA P104-100 (GP104, 10de:1b87), PCI BDF `0000:03:00.0`
- Upstream Root Port: `0000:00:02.0`
- GPU1: `0000:04:00.0`, kept bound to NVIDIA
- GPU0 unbound from NVIDIA during the experiment
- Only this **live session** was verified; persistence across reboot, NVIDIA rebind, CUDA and Ollama are not yet tested.

## Verified sequence

1. Staged BAR0 preparation and native `0x8C040` SPEED write, with GPU and Root TLS=2.
2. Windows-compatible `ApplyLiveGroup()` completed successfully on Linux:
   - Seven unchanged entries skipped.
   - Exactly one native MMIO store returned for `0x88610: 0x00000000 -> 0x00000001`.
   - Masked readback `0x00000001`, `GROUP PASS`.
   - `0x8C1C0=0x00120032` (SYSTEM_MAX_SPEED bit20 retained).
3. **After GROUP PASS**, one standard Root Port Retrain Link operation:
   - `0000:00:02.0` Link Control offset `0xA0`, 16-bit write `0x0040 -> 0x0060`.
   - Driver returned a 2-byte write. No endpoint Retrain Link, reset, MMIO rewrite, retries or CHANGE_SPEED.
   - Root observation saw `0x7842` (Training=1, Gen2 x4) followed by `0x7042` (Training=0, Gen2 x4).
   - Root Gen2 x4 observed stable for ~1.9998 seconds in the bounded observation window, AER zero.
4. The retrain runner **reported FAIL**, reason `GPU CAP/CAP2 must be 00453C42/6`; its final GPU capability equality guard was not satisfied. This does **not** invalidate the independently observed live Gen2 x4. Do not relabel the runner output PASS.
5. Subsequent operator read-only `lspci -vv` confirmed **both endpoints**:
   - GPU0 LnkSta: `Speed 5GT/s, Width x4`
   - Root Port LnkSta: `Speed 5GT/s, Width x4`
   - GPU0 LnkCap: `Speed 5GT/s, Width x4`
   - GPU0 LnkCap2: `Supported Link Speeds: 2.5-5GT/s`
   - Both LnkCtl2: `Target Link Speed: 5GT/s`
   - GPU1 still listed by `nvidia-smi`.

## Interpretation / cautions

**Physical PCIe Gen2 x4 was confirmed by subsequent independent user-side PCI enumeration.** The runner itself intentionally returned FAIL on a stricter post-retrain GPU capability check; the final lspci output is the evidence for both ends.

The previous Root-only retrain at VSEC=0 did not reach Gen2. The successful link transition occurred after VSEC=1 and full ApplyLiveGroup. This is evidence for the ordered sequence, not proof that VSEC alone caused the transition.

Do not claim persistence over reset or NVIDIA binding. Rebinding NVIDIA may renegotiate the link. No further hardware writes are part of this evidence commit.
